    Surveillance

    Ajoutez des nœuds depuis Messages → détails d'un message → « 👁 surveiller ». Chaque minute, l'appli vérifie si le nœud a été entendu récemment : advert, message, paquet qu'il a relayé ou réponse à une sonde de statut. S'il ne l'est plus depuis le seuil choisi, il passe hors ligne et vous êtes alerté. La surveillance tourne tant que cette page est ouverte et la radio connectée.

    Annuaire des répéteurs

    Sert à identifier les empreintes de sauts inconnues de votre radio. D'abord les nœuds entendus par votre radio, puis cet annuaire, toujours avec filtrage géographique.

    Hors ligne : ouvrez une fois dans le navigateur, enregistrez la page (fichier .json) puis importez-la ici. Formats acceptés : CoreScope (nodes[], public_key, lat/lon) ou liste équivalente.

    Application

    L'historique des messages est stocké uniquement dans ce navigateur (localStorage), séparément pour chaque radio. Web Serial et Web Bluetooth nécessitent Chrome, Edge ou Opera (Bluetooth aussi sur Chrome Android).
